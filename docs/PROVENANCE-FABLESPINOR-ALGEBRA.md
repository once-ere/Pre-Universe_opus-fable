### 3.1 The stricter form: assertions **and** zero kernel messages

A Wolfram script can pass every `VerificationTest` while the kernel still
emits a message such as `Limit::alimv` on the way, and `wolframscript` does not
turn such messages into a non-zero exit status. The repository therefore ships
a verifier that loads the source with `$MessageList` captured and fails if
**any** message was generated:

```bash
cd Pre-Universe_opus-fable
wolframscript -file tests/verify_wolfram_source.wls wolfram/fable_spinor.wls \
  2>&1 | tee logs/verify-fable-spinor.log
```

The last lines of the log must read, with a machine-dependent seconds value:

```

Source verifier messages : 0
Source verifier succeeded: 30
Source verifier failed   : 0
```

Exit status `0` is the pass certificate; `1` means at least one assertion

## 4. What the script defines

### 4.1 The real Clifford algebra

The eight generators of $\mathrm{Cl}(4,4)$ are built as raising and lowering
operators on the exterior algebra of $\mathbb{R}^4$, ordered so that even-parity
states occupy components 1–8 (the **type-one** block) and odd-parity states
occupy 9–16:

```
gamma^i       = c_i + a_i    for i = 1..4   (square +1, symmetric)
gamma^{4+i}   = c_i - a_i    for i = 1..4   (square -1, antisymmetric)
```

Every entry is an integer, so the representation is real in the strongest
possible sense. The script verifies

$$\tfrac12\{\gamma^a,\gamma^b\} = \eta^{ab}\mathbb{1}_{16},
\qquad \eta = \mathrm{diag}(1,1,1,1,-1,-1,-1,-1).$$

### 4.2 The spinor metric

$$C=\gamma^1\gamma^2\gamma^3\gamma^4 .$$

The script proves $C^{\mathsf T}=C$ and $(C\gamma^a)^{\mathsf T}=-C\gamma^a$, and
that $S^{ab\,\mathsf T}C+CS^{ab}=0$ so the bilinear is $\mathrm{Spin}(4,4)$
invariant. For a **commuting real** field this pairing is exactly the one that
works: the scalar survives and the vector current dies.

| bilinear | built from | fate for a commuting real spinor |
|---|---|---|
| $S=\Psi^{\mathsf T}C\Psi$ | $C$ symmetric | nonzero — the cosmological variable |
| $P=\Psi^{\mathsf T}C\gamma_9\Psi$ | symmetric | nonzero |
| $J^a=\Psi^{\mathsf T}C\gamma^a\Psi$ | $C\gamma^a$ antisymmetric | **identically zero** |

### 4.3 Irreducibility under the universal cover of the real $O(4,4)$

$O(4,4)$ is generated by reflections, whose lifts are the $\gamma^a$ themselves;
they generate $\mathrm{Pin}(4,4)$. The even part is the connected
$\mathrm{Spin}(4,4)$, generated by $S^{ab}=\tfrac14[\gamma^a,\gamma^b]$.

Real Schur's lemma: the representation is absolutely irreducible over
$\mathbb{R}$ exactly when its commutant is one-dimensional. The commutant is
computed as the kernel of the stacked map $X\mapsto gX-Xg$.

| group | commutant dimension | verdict |
|---|---|---|
| $\mathrm{Pin}(4,4)$ | **1** | absolutely irreducible |
| $\mathrm{Spin}(4,4)$ | **2** | reducible, $16=8\oplus 8$ |

The second row is the reason the *full* $O(4,4)$ is required and why a
construction such as $\mathbb{1}_4\otimes\gamma^\mu$ — a direct sum of four
$3+1$ Dirac spinors — does not answer the question. The chirality operator
commutes with every $S^{ab}$ but anticommutes with every $\gamma^a$, so a
reflection exchanges the two halves and glues them into one irreducible 16.

Independently, the 256 Clifford words span the whole real $16\times16$ matrix
algebra (rank 256) while the 128 even words span exactly half (rank 128).

### 4.4 Lagrangian, field equation and energy–momentum tensor

With $\gamma^\mu=e^\mu{}_a\gamma^a$ and $D_\mu$ the gpt-5.6_bridge covariant
derivative,

$$\mathcal{L}=e\Bigl[\tfrac12\bigl(\Psi^{\mathsf T}C\gamma^\mu D_\mu\Psi
-(D_\mu\Psi)^{\mathsf T}C\gamma^\mu\Psi\bigr)-MS-V(S)\Bigr],$$

whose Euler–Lagrange equation is $\gamma^\mu D_\mu\Psi=(M+V'(S))\Psi$. In the
homogeneous flat reduction, including the bridge's scalar connection term, that
is

```
gammaTime . (Psi' + (3/2) H Psi - (1/2)(1-h) Theta Psi) == (M + V'(S)) Psi
```

The script derives the following **with a generic 16-component $\Psi$** — no
component is ever specialised:

| quantity | result | why |
|---|---|---|
| $\dot S+\nu H S$ | $0$ | $C$ symmetric, $C\gamma^0$ antisymmetric |
| $\Psi^{\mathsf T}C\gamma^0\Psi$ | $0$ | $C\gamma^0$ antisymmetric |
| on-shell $\mathcal{L}$ | $SV'(S)-V(S)$ | substitute the field equation |
| energy density $\rho$ | $M S+V(S)$ | $T^0{}_0$ minus the on-shell Lagrangian |

with the **dilution exponent**

$$\nu(s)=3-\xi\bigl(1-h(s)\bigr),\qquad h(s)=3s^2-2s^3 .$$

The pressure is then fixed uniquely by covariant conservation,

$$p=\frac{\nu}{3}\bigl(MS+n\lambda S^{n}\bigr)-\rho
\quad\text{for}\quad V(S)=\lambda S^{n},$$

and the script checks $\mathrm{d}\rho/\mathrm{d}N+3(\rho+p)=0$ identically.

### 4.5 Kinetic energy, potential energy, pressure, density, $w$

| name | expression |
|---|---|
| kinetic energy density | $\Psi^{\mathsf T}C\gamma^\mu D_\mu\Psi = (M+V'(S))S$ |
| potential energy density | $V(S)=\lambda S^{n}$ |
| energy density | $\rho = M S+\lambda S^{n}$ |
| pressure | $p = \bigl(\tfrac{\nu}{3}-1\bigr)MS+\bigl(\tfrac{n\nu}{3}-1\bigr)\lambda S^{n}$ |
| equation of state | $w=p/\rho$ |
| dust-like component | $w_{\text{dust}}=\nu/3-1$ |
| dark-energy-like component | $w_{\text{potential}}=n\nu/3-1$ |

### 4.6 The closed-form solution

With the bridge field obeying $\mathrm{d}s/\mathrm{d}N=\gamma s(1-s)$,

$$s(N)=\frac{s_0e^{\gamma N}}{1-s_0+s_0e^{\gamma N}},\qquad
\ln S(N)=\ln S_0-3N+\frac{\xi}{\gamma}\Bigl[\ln s+s-s^{2}\Bigr]_{s(0)}^{s(N)} .$$

The script verifies that differentiating this reproduces $-\nu(s(N))$ exactly,
using $(1/s+1-2s)\,s(1-s)=1-h(s)$.

Reading those four physical lines:

Each block below is complete and standalone; paste it into a terminal from the
repository root.

Confirm the Clifford relation and the reality of the generators:

```bash
wolframscript -code '
exteriorBasis = Join[Select[Range[0,15], EvenQ[DigitCount[#,2,1]]&],
                     Select[Range[0,15], OddQ[DigitCount[#,2,1]]&]];
pos[s_] := First[FirstPosition[exteriorBasis, s]];
occ[s_,i_] := BitAnd[s, 2^(i-1)] != 0;
sgn[s_,i_] := (-1)^Total[Boole[occ[s,#]]& /@ Range[i-1]];
cre[i_] := Normal@SparseArray[Table[With[{s=exteriorBasis[[c]]},
  If[occ[s,i], Nothing, {pos[s+2^(i-1)],c} -> sgn[s,i]]], {c,16}], {16,16}];
ann[i_] := Normal@SparseArray[Table[With[{s=exteriorBasis[[c]]},
  If[occ[s,i], {pos[s-2^(i-1)],c} -> sgn[s,i], Nothing]], {c,16}], {16,16}];
g = Join[Table[cre[i]+ann[i],{i,4}], Table[cre[i]-ann[i],{i,4}]];
eta = DiagonalMatrix[{1,1,1,1,-1,-1,-1,-1}];
Print["integer entries : ", And @@ (IntegerQ /@ Flatten[g])];
```

## 8. Honest limits of this page

- This is a **background** model: one homogeneous field in a spatially flat
  universe. No perturbations are computed, so nothing here constrains structure
  formation.
- $w=-0.764$ is reproduced as an **exact limit of the model**, not as a fit to
  data. No supernova, BAO or CMB likelihood is evaluated anywhere in this
  repository.
- The logistic law $\mathrm{d}s/\mathrm{d}N=\gamma s(1-s)$ for the bridge field
  is a **phenomenological closure**, chosen because it is smooth, bounded in
  $(0,1)$ and analytically integrable. It is not derived from an action.
- No claim is made that a new fundamental particle has been observed.
